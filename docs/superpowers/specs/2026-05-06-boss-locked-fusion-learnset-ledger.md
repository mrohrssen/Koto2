# Boss-Locked Fusion Learnset Ledger

**Date:** 2026-05-06  
**Purpose:** Human-authored stat and learnset rationale for the 10 boss-locked fusion creatures.

## Rules

- No algorithmic moveset assignment.
- Each fusion blends both ingredient identities.
- Each fusion is stronger than ordinary creatures, with rare fusions above uncommon fusions.
- Each fusion has exactly one legal level-1 damage move.
- Each fusion has 5-6 authored moves.

## Fusion Learnsets
