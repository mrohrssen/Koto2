# Tutorial: Hiragana + Romaji Translator Demo — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace filler prologue pages 07–09 with a 5-page interactive demo where Cid renders `こんにちは` in the game's standard "pronunciation above, definition below" layout, so new players see and tap their first Japanese word before real content arrives.

**Architecture:** Content-driven change (frame-sources.json + prologue.json) plus two tiny code touchpoints: a resolver in the existing `/api/game/prologue` route (server-side token lookup by frame group) and a new branch in the existing `playPrologue` client loop (token → HTML via renderJpSentence). No new functions, modules, endpoints, or imports.

**Tech Stack:** Node.js + Express (server), vanilla JS modules + Vite (client), Sudachi tokenizer pipeline (via `scripts/tokenize-static.js`), node:test (unit tests), Playwright MCP (manual playtest).

import express from 'express';
import http from 'http';
import { loadDialoguePools } from '../../../src/game/dialogue-loader.js';
import createMiscRoutes from '../../../src/routes/game/misc.js';

// Helper — spins up the router on an ephemeral port, makes one GET, returns body
async function getJson(app, path) {
  return new Promise((resolve, reject) => {
    const server = app.listen(0, '127.0.0.1', () => {
      const port = server.address().port;
      const req = http.request(
        { host: '127.0.0.1', port, path, method: 'GET' },
        res => {
          let data = '';
          res.on('data', c => { data += c; });
          res.on('end', () => {
            server.close();
            try { resolve(JSON.parse(data)); } catch (e) { reject(e); }
          });
        }
      );
      req.on('error', err => { server.close(); reject(err); });
      req.end();
    });
  });
}

describe('prologue route — GET /prologue', () => {
  it('attaches resolved tokens to jpDemo entries', async () => {

```javascript
  // Get prologue scenes — resolves jpDemo tokens from the dialogue pool
  let _prologueCache = null;
  router.get('/prologue', (_req, res) => {
    if (!_prologueCache) {
      const filePath = join(__dirname, '../../../data/prologue.json');
      const raw = JSON.parse(readFileSync(filePath, 'utf-8'));
      _prologueCache = raw.map(scene => {
        if (scene.type === 'jpDemo' && scene.frameGroup) {
          const script = getCidScripts().find(s => s.id === scene.frameGroup);
          const tokens = script?.lines?.[0]?.tokens;
          return tokens ? { ...scene, tokens } : scene;
        }
        return scene;
      });
    }
    res.json(_prologueCache);
  });
```

Leave `_prologueCache` declared with `let` at the same scope — the cache semantics are preserved (first request builds, subsequent requests return cached).
