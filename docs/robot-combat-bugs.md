# Robot Combat - Known Bugs

## 1. Chips are not clickable
Chips cannot be clicked to view stats/descriptions. Should be clickable like the old combat system. This is also needed for the menu to allow using chip skills.

## 2. HP does not update in real time
Health bars don't update on the frontend as each robot deals damage. HP should update immediately as damage is dealt from each robot, not all at once.

## 3. Chip skills don't charge
Chip skills don't appear to gain charge at all. They should charge +1 per chip after each fight.

## 4. Robot base attack stats too high
Robot base attack stats should be halved across the board. Other stats (HP, etc.) remain untouched — this is specifically the robot's attack stat, not chip skills.
