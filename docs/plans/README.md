# Plans Directory

Active implementation plans go here. Completed plans are moved to `archive/`.

## Structure

- **Root directory**: Active plans being worked on now
- **archive/**: Completed or abandoned plans (kept for historical reference)

## Naming Convention

Plans follow the date-first naming pattern for easy chronological organization:

```
YYYY-MM-DD-feature-name.md
```

Examples:
- `2026-01-27-documentation-overhaul.md` - Active implementation plan
- `2026-01-27-documentation-overhaul-design.md` - Design phase for the above
- `2026-01-26-mobile-testing-workflow-design.md` - Recent workflow design

## When to Archive

Move a plan to `archive/` when:
- Implementation is complete
- The feature is abandoned or replaced
- The plan has been superseded by a newer approach
- It's historical reference material from prior work

Keep in root when:
- Currently implementing (within the last 2-3 days)
- Actively designing before implementation starts
- Referenced by ongoing work
